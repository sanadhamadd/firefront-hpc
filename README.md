# FireFront-HPC

A parallel wildfire spread simulator. A 2-D cellular automaton written in C and parallelized with MPI + OpenMP, with a GPU port (CUDA/OpenACC) as an additional experiment, run through Slurm on an HPC cluster.

**Team:** Sanad, Alejandro, Alicia, Rodrigo, Khadeja

**Status:** in development. Results, build and run instructions will be added as the project progresses.
